# Lucaslei 统一应用

一个入口，管理所有功能：菜谱、采购、体重、待办。

## 功能

- 🍳 **菜谱** - 35道孕期菜谱，四川风味
- 🛒 **采购** - 装修采购清单管理
- ⚖️ **体重** - 体重记录与注射管理
- 📋 **待办** - 待办事项管理

## 安装

### 方式一：网页版
直接打开：https://app.lucaslei.cyou

手机浏览器打开后，可以"添加到主屏幕"，像 APP 一样使用。

### 方式二：APK
1. 进入 Actions 页面
2. 选择最新的构建
3. 下载 APK 文件
4. 安装到手机

## 更新

修改代码后推送到 main 分支，GitHub Actions 会自动打包新的 APK。
